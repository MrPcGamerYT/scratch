# Third-party software in the Project Nexus development bundle

The VM engine is a **modified QEMU 10.2.0** build, not a new emulator written by Project Nexus. QEMU is primarily distributed as GPL version 2 (individual files and included firmware can have different terms). See `COPYING`, `LICENSE`, and `README` in this folder. QEMU is a trademark of Fabrice Bellard; this project is not endorsed by QEMU.

- QEMU base revision: `698104725efad4b29079d857dfdebbd804e34c99` (tag v10.2.0). Project Nexus modified the SDL2 renderer, SDL2 console header, and UI trace definitions on 2026-11-23. The source archive includes the applied Nexus SDL2 batching patch, also included separately in `../sources/patches/`; source included in `../sources/qemu-10.2.0.tar.gz`. Original: https://github.com/qemu/qemu/tree/v10.2.0
- The x86 PC and VGA BIOS binaries are the SeaBIOS 1.17.0 images supplied in QEMU's `pc-bios`. Source is included in `../sources/seabios-1.17.0.tar.gz`, revision `b52ca86e094d19b58e2304417787e96b940e39c6`. See QEMU's `pc-bios/README` and the SeaBIOS source for license details.
- The UEFI images `edk2-x86_64-code.fd` and `edk2-i386-vars.fd` are the unmodified binaries supplied by QEMU at the pinned revision. QEMU's `pc-bios/README` identifies TianoCore edk2 tag `edk2-stable202302` and OpenSSL tag `OpenSSL_1_1_1s`; see the supplied `edk2-licenses.txt` and upstream source at https://github.com/tianocore/edk2/tree/edk2-stable202302 and https://github.com/openssl/openssl/tree/OpenSSL_1_1_1s. These binaries have separate terms; review all notices and source obligations before public release.
- The build script is included in `../sources/build-qemu.sh`. The runtime DLLs come from MSYS2 packages; `msys2-installed-packages.txt` records the build environment and `msys2/` contains the available installed package license texts. MSYS2 packaging recipes and source information are at https://github.com/msys2/MINGW-packages. Each dependency has its own license and source requirements.
